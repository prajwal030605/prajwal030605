### 📍 [SmartTour](https://github.com/prajwal030605/smarttour_live) — [Live ↗](https://smarttour-live.vercel.app)
> AI-based tourist crowd intelligence for **10 Uttarakhand destinations**

Led a 3-person team. Owned the architecture, geofencing, and forecasting.

- **GPS geofence state machine** — 60s dwell timer, 30s debounce, 200m accuracy gate, smallest-radius-wins zone resolution
- **Holt-Winters Triple Exponential Smoothing** — 7-day visitor forecasting with weekly seasonality + festival multipliers
- **11-table Postgres schema** with RLS, idempotent migrations, UNIQUE double-entry prevention
- **15 serverless API routes** with HTTP 429 quota enforcement for sensitive Char Dham sites
- Installable **PWA** with cache-first service worker + email-OTP vehicle binding

`Next.js 14` `TypeScript` `Supabase` `PostgreSQL` `react-leaflet` `Recharts` `PWA` `Vercel`
